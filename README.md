## ⚙️ Base de Datos
Este proyecto utiliza **MySQL**[cite: 1]. Para inicializar la base de datos con las tablas y datos de prueba necesarios:
1. Crea una base de datos local con el nombre `spartacus_gym`[cite: 1].
2. Ejecuta el script ubicado en `database/script_spartacus_gym_corregido.sql` utilizando tu cliente de MySQL preferido (MySQL Workbench, DBeaver, etc.).
