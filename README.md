🏋️‍♂️ Gestor-GYM

Un sistema de gestión integral para gimnasios diseñado para optimizar el control de socios, pagos, membresías y la administración diaria.

🚀 Características Principales

Gestión de Socios: Alta, baja, modificación y consulta del historial de clientes.

Control de Membresías y Pagos: Administración de planes, vencimientos y registro de cobros.

Dashboard / Panel Administrativo: Métricas y visualización rápida del estado del gimnasio.

Control de Accesos: Verificación del estado de cuota para el ingreso de usuarios.

🛠️ Tecnologías Utilizadas

Frontend: HTML, CSS, JavaScript (o framework según aplique)

Backend: Node.js / Python / .NET / PHP

Base de Datos: PostgreSQL / MySQL / MongoDB / SQLite

💻 Requisitos Previos

Antes de comenzar, asegúrate de tener instalado:

Git

Entorno de ejecución según el stack técnico del proyecto (ej. Node.js, Python, .NET).

Sistema de gestión de bases de datos correspondiente.

⚙️ Instalación y Configuración

Clonar el repositorio:

git clone https://github.com/NahuuR7/Gestor-GYM.git
cd Gestor-GYM


Instalar dependencias:

# Si usas Node.js / npm:
npm install

# Si usas Python:
pip install -r requirements.txt


Configurar variables de entorno:
Crea un archivo .env en la raíz del proyecto configurando las credenciales necesarias:

PORT=3000
DB_HOST=localhost
DB_USER=tu_usuario
DB_PASSWORD=tu_contraseña


Ejecutar la aplicación:

# Modo desarrollo
npm run dev
# o ejecutable según el entorno
